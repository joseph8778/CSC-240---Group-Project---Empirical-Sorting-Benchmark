# CSC-240---Group-Project---Empirical-Sorting-Benchmark
he application operates as a digital stopwatch and metric recorder. It evaluates four distinct sorting algorithms, Insertion Sort, Mergesort, Quicksort, and Heapsort, cross three dataset versions: a completely random dataset, nearly-sorted (90% sorted) set, and reverse-sorted data set across varying dataset sizes (N = 1,000 to N = 100,000)
