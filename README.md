# CSC240 Sorting Benchmark

A C++ sorting benchmark project.

## Project layout

- `include/` contains header files.
- `src/` contains implementation files and the program entry point.

## Build

With GNU Make and a C++17 compiler installed, run:

```sh
make
```

The build produces `sorting_benchmark` in the project root. To remove the
generated executable, run:

```sh
make clean
```
